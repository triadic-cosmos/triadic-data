# Triadic Data

**Triadic Data** contains the datasets, trained models, and generated artifacts  
produced by the **Triadic Toys** and the **Triadic System**.

All content in this repository — except provided curriculum data —  
is generated *exclusively* by the toy universes or the DMLG pipeline,  
and is provided for reproducibility, inspection, and educational use.

This repository is the data companion to:

- **triadic-toys** — runnable Java toy universes (Apache License 2.0)  
- **triadic-system** — Python-based DMLG implementation (GNU AGPL‑3.0)  
- **triadic-cosmos** — canonical books and papers (CC BY‑NC‑ND 4.0)

All files in **triadic-data** are released under the **MIT License**.

The system project that generates these artifacts is licensed separately under  
**GNU Affero General Public License, Version 3.0**, which governs the source code  
in the `triadic-system` repository.

The toy projects that generate these artifacts are licensed separately under  
**Apache License 2.0**, which governs the source code in the `triadic-toys` repository.

---

## Purpose

The goal of this repository is to:

- store **trained models** produced by the toy universes and the DMLG system  
- provide **datasets** required to run or reproduce experiments  
- archive **generated artifacts** such as galleries, logs, statistics, and model output  
- ensure that all Triadic Toys can be run **without retraining**  
- support transparent, inspectable, and reproducible research

This repository contains **no external datasets** and **no manually curated data**,  
except for curriculum texts explicitly included for training purposes.

## Relation to Other Repositories

### **triadic-cosmos**  
Canonical books and scientific papers defining the theoretical foundations  
of the Triadic Cosmos. Licensed under **CC BY‑NC‑ND 4.0**.

### **triadic-toys**  
Runnable Java toy universes that generate data stored here.  
Source code is licensed under **Apache License 2.0**.

### **triadic-system**  
Python-based reference implementation for the DMLG (Dynamic Modular Language Graph).  
Source code is licensed under **AGPL‑3.0**.

This project produces several categories of data stored in the  
`toy-system/` folder inside *triadic-data*, consistent with all other toy projects:

- **Curriculum texts**  
  - Original texts authored for the Triadic Cosmos  
  - Public-domain texts (e.g., Project Gutenberg) with their respective licenses  
  - Canonicalised versions of these texts (lemma-normalised, structurally reduced)

- **Trained models**  
  - Binary `.bin` model files generated by the DMLG training pipeline  

- **Example outputs**  
  - Generated text samples

### **triadic-data** *(this repository)*  
Generated datasets, trained models, and artifacts produced by the toys and the DMLG system.  
MIT‑licensed for full reuse and experimentation.
